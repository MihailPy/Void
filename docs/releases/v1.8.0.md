# Void v1.8.0

## Highlights

- Project-aware assistant with JSON-backed project context.
- Clarification flow for missing project and command selections.
- Safe project command execution by configured command key.
- Managed browser sessions, including visible Void-owned browser windows.
- Visible terminal runner for approved predefined project commands.
- Unified approval experience across CLI, API, and Web UI.

## Known Limitations

- No arbitrary shell execution.
- No planner.
- No autonomous multi-step execution.
- No terminal output streaming.
- No attach to personal browser.
