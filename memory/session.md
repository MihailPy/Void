- **Почему self-tool не подходит**: Требует сетевых запросов (security restriction)
- **Сигнатура**: `network_request(url, method='GET', headers=None, params=None)`
- **Поведение**: Выполняет HTTP/HTTPS запросы и возвращает ответ
- **Пример кода**:

```python
import requests
def run(args):
    url = args.get('url')
    method = args.get('method', 'GET')
    headers = args.get('headers', {})
    params = args.get('params', {})
    response = requests.request(method, url, headers=headers, params=params)
    return {'status_code': response.status_code, 'text': response.text}
```

- **Пример использования**: Получение погоды, курсы валют, новости

**2. request_capability: git_operations**

- **Поведение**: Выполняет безопасные запросы с параметризованными значениями
