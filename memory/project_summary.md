# Project Summary

## Тип проекта
Локальный AI-помощник на Python

## Описание
Void — локальный AI-помощник, который использует LLM для принятия решений и умеет работать с инструментами:
- читать файлы
- записывать файлы
- смотреть список файлов
- выполнять безопасные команды
- создавать self-tools

## Цель проекта
Создать персонального AI-агента, который может помогать с разработкой, анализом файлов и автоматизацией задач.

## Текущая версия
- Agent Loop
- Structured JSON output
- File-based memory
- Self-tools
- Planning step
