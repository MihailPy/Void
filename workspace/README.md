# Void

Void — локальный AI-помощник на Python.

Он использует LLM для принятия решений и умеет работать с инструментами:

- читать файлы
- записывать файлы
- смотреть список файлов
- выполнять безопасные команды
- создавать self-tools

Цель проекта — создать персонального AI-агента,
который может помогать с разработкой, анализом файлов и автоматизацией задач.

Текущая версия:

- Agent Loop
- Structured JSON output
- File-based memory
- Self-tools
- Planning step
